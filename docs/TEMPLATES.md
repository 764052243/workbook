# Codex 常用任务模板

适用偏好：保留默认 `xhigh`；常用浏览器、电脑操作、Word/PDF、Excel、网站制作，以及视频、小说和 AI 漫剧任务。

只需补充当前任务有用的字段。目标足够明确时直接执行；缺少会影响结果的关键信息时再询问。既有项目公约、权限和验收要求继续适用。

## 1. 最简通用模板

```text
目标：[希望最终得到什么]
材料/范围：[文件、目录、网页或现有作品；未知则先定位]
验收/交付：[成功条件、输出形式或篇幅]
```

例如：修复页面在手机上横向溢出的问题。先定位相关 HTML/CSS/JS，保持业务逻辑，浏览器验证后说明改动和结果。

## 2. CSS / JS / HTML / Java 开发与排查

```text
在 [项目目录/分支] 处理 [功能或故障]。
现象及复现：[步骤、关键错误；没有则先复现]
重点范围：[模块/页面/接口；不确定则搜索定位]
验收：[具体行为或项目已有测试要求]
先定位再读取相关代码，保持必要修改；按项目公约完成协同检查和验收。
报告简述根因、修改、验证及剩余问题；完整日志保存文件，必要时引用。
```

不要预设所有任务都需要重构、全仓审查或全量重建。测试范围根据改动及项目强制要求确定。

## 3. 网站制作与浏览器验证

```text
制作/修改 [网站或页面]，面向 [用户]，核心功能是 [功能]。
参考与材料：[现有网址/项目/截图/文案；可省略]
验收：[关键操作、手机与桌面表现、交付形式]
先完成可预览成果并验证关键流程；沿用现有项目结构和设计约定。
```

网站发布、外部账户登录及对外发送等操作，按本次任务授权范围处理。

## 4. Word / PDF / Excel

```text
基于 [文件路径或材料] 制作/修改 [文档/PDF/工作簿]。
用途与受众：[用途]
重点要求：[版式、字段、公式、图表、页数或数据口径]
交付：[文件格式和保存位置]
按任务检查排版或公式/数据正确性，最终提供文件和简短说明。
```

文档正文、完整表格和用户指定篇幅属于交付要求，不按“简短回复”擅自删减。

## 5. 小说创作

```text
作品与本次目标：[大纲/人物/续写/第几章/修订]
风格与读者：[题材、视角、语气；可省略]
必须延续的设定：[设定文件和直接相关前文]
本次剧情：[冲突、转折、结尾；可由你提出]
交付：[正文/大纲、目标篇幅、保存位置]
先读取相关设定和必要前文；信息不足再补读。保持人物动机、时间线和伏笔一致。
直接交付所需创作内容，说明文字简短。
```

长篇连载可维护简短的人物、时间线和伏笔记录，并保留前文路径；不反复贴入全部小说。

## 6. AI 漫剧

```text
制作 [剧名/第几集/某段场景] 的 [剧本/分镜/画面提示词/配音稿/成片]。
参考材料：[人物设定、前集摘要、已有素材]
规格：[时长、画幅、风格和目标平台]
剧情目标：[冲突、关键情绪、结尾钩子]
交付：[所需文件或表格字段]
围绕本集和直接依赖的设定工作，保持角色外观、场景、台词与镜头连续性。
区分已有素材与待生成素材，避免反复生成已验收的镜头。
```

用户未指定时，根据任务选择必要字段，例如镜号、时长、画面、台词、音效和素材状态；不机械增加无用列。

## 7. 视频任务

```text
用 [源素材路径] 完成 [剪辑/字幕/配音/封面/生成视频]。
规格：[时长、分辨率、画幅、格式]
节奏与内容：[保留内容、参考风格]
交付：[成片、字幕、工程或素材清单]
先定位必要素材并检查规格，保留源文件；成片后验证时长、音画、字幕及导出结果。
```

具体生成、配音或平台上传能力以当前工具和账户实际可用情况为准；需要外部服务时再处理连接，不预先安装无关插件。

## 8. 独立任务交接

```text
项目/作品与分支：
当前目标：
已完成与证据路径：
修改文件/素材状态：
验证结果：
未解决问题与限制：
必须遵守的规则：
下一步：
```

同一任务需要保留调查上下文时继续当前聊天；切换独立任务时使用简短交接。摘要不能替代需要核验的原始文件。
